Codex 侧栏增强器（Windows 本地适配版）

安装：
  powershell -NoProfile -ExecutionPolicy Bypass -File .\install-windows.ps1

使用：
  从桌面或开始菜单打开“Codex 侧栏增强器”。
  首次打开时，如果 Codex 正在运行，启动器会自动重启一次 Codex。
  如果检测到本机现有的资产控制台服务，侧栏快捷区会显示“资产控制台”。“站点”和“插件”不再占用常用入口；新增“Skill 管理”，点击后直接进入技能工作台。
  Skill 管理会读取全部已安装 Skill，默认以单列清单显示 10 个常用能力，并按“视频创作 / 导演镜头 / 画面风格 / 资产工作台 / 写作研究 / 工具管理”归类。支持按名称或用途搜索；点星标可调整“常用”，选择会保存在本机。需要 Codex 原有来源筛选时，可点“完整列表”临时展开，Skill 详情和启停操作仍使用原生界面。
  “＋ 新建文件夹”和文件夹卡片上的“改名”需要配套资产控制台服务支持 POST/PATCH /api/folders；当前电脑已经同步升级。若把本压缩包迁移到其他电脑，请先安装或升级配套 AssetBrowser 服务。
  点击后会打开“当前任务资产”工作区，不再把独立版控制台原样塞进来，也不另开浏览器。
  它会识别当前 Codex 任务；“待处理 / 项目素材 / 精选库”表示文件位置，“关联项目”单独决定当前任务的项目目标，今日练习作为临时工作区保留。“选择项目”里可直接点“新建项目”，填写项目名和一个已有的 Windows 文件夹后，新建并关联当前任务。
  可在主区域直接搜索和筛选。多个扫描目录和子文件夹会完整显示为可切换层级；左栏目录、主区文件夹卡片和顶部路径都能直接点击切换。每张文件夹卡都直接提供“改名”和“打开”，改名只变更目录名称，素材不动；扫描目录和自动归档路径会同步更新。进入项目文件夹后，一级工具栏会直接显示“自动整理”，整理当前文件夹全部素材，不受搜索和筛选影响；每日练习保留当前日期目录，已经归位的不重复移动，成片/最终输出区不参与，操作后可撤销。批量选择后，可明确“移动到项目”“附加到当前对话”或“丢弃（不删除）”；即使当前任务尚未关联项目，“移动到项目”也会直接让你选目标，不再卡住。移动窗口也保留“自动整理”：单素材区项目会按素材类型自动归位，巫女怪猎按“集数 / 参考或生成视频”整理，每日练习按“当天 / 图片或视频”整理；多素材区无法确定时会先让你选对应素材区。也可以继续手动选择文件夹。对比、精选、其他移动和永久删除收在“批量工具”中。移动、标记和删除均提供撤销。
  大文件夹不会再一次加载所有素材预览：先显示当前屏幕附近内容，向下滚动时再继续加载，切换项目和文件夹也不会等待退场动画后才开始读取。已经打开过的最近 24 个位置会先显示内存缓存，再在后台自动更新；手动刷新始终读取最新内容。
  “待处理 / 项目素材 / 精选库”切换带有轻量过渡，系统开启“减少动态效果”时会自动关闭动画。
  选择 2–4 项可并排对比，并直接做项目移动、丢弃、精选或对话附件决策。最多 8 项一次附加到当前对话输入框（不会自动发送）；完成后可一键返回对话并聚焦输入框。
  未检测到本机资产控制台时，对应入口自动保留“搜索”。
  常用快捷入口和“置顶 / 项目 / 最近”切换栏独立占据侧栏顶部空间，不覆盖任务；鼠标停在顶部控件上滚轮时，也只滚动下面的任务内容。

卸载：
  从开始菜单打开“卸载 Codex 侧栏增强器”。

工作方式：
  - 只读取当前用户的 .codex 会话索引和会话文件。
  - 仅通过 127.0.0.1:9231 连接 Codex 的本地调试端口。
  - 资产控制台内嵌连接每次打开都会更换随机地址标记，并在关闭时撤销。
  - 不修改 WindowsApps 中的 Codex 应用，不修改对话正文。
  - 不向外部服务器上传对话、摘要或额度信息。
  - 安装和卸载仅操作 LOCALAPPDATA 下的专属目录。
