Codex Sidebar Enhancer - Windows 验证摘要

- Codex 原生侧栏布局保持不变：常用入口调整为“新对话 / 已安排 / Skill 管理 / 项目管理 / 资产控制台”，不常用的“站点 / 插件”移出快捷区；双列任务卡与现有滚动方式保持不变。
- Skill 管理读取完整安装目录，默认以单列清单显示 10 个常用项，并按实际创作流程整理为“常用 / 视频创作 / 导演镜头 / 画面风格 / 资产工作台 / 写作研究 / 工具管理 / 全部”；支持本地搜索、星标常用和完整列表回退，点击自定义条目仍打开 Codex 原生详情。
- 资产控制台改为“待处理 / 项目素材 / 精选库”，项目关系与筛选状态更清楚。
- 嵌入态“选择项目”现可直接“新建项目”：选择已有 Windows 文件夹后会新建并关联当前任务。
- 新建流程只接受 Windows/UNC 绝对路径；项目建成但自动关联失败时会明确告知，避免重复新建。
- 批量选择后只保留高频动作；对比、状态、精选库和永久删除收进“批量工具”。
- “丢弃（不删除）”不会删除源文件；永久删除仍位于二级危险操作区。
- 对比台可直接附加到对话、移动项目、标记状态、丢弃或收入精选库。
- “移动到项目”不再依赖任务先完成关联：未关联时直接选择目标；项目页一级工具栏提供“自动整理”，直接整理当前文件夹全部素材并保留当前日期/案例边界；移动窗口也保留一键整理。两处均按图片/视频/音频类型归位，全程限制在项目扫描目录内，多素材区无法可靠判断时要求先选择，成片与最终输出区禁止自动整理。
- 多扫描目录会补齐缺失的根层级；左栏目录、文件夹预览卡和顶部面包屑均可切换到对应层级，空的扫描目录也不会消失。
- “待处理 / 项目素材 / 精选库”切换加入克制的淡出、位移动画，并遵循系统的“减少动态效果”设置。
- 附加完成后会明确提示“已写入、未发送”，可继续挑选或返回对话并聚焦输入框。
- 无结果时可一键清除搜索与筛选；资产卡支持键盘操作，选择热区已放大。
- 切换 Codex 任务时，已打开的资产面板会同步到新任务上下文。
- 资产仅接受 Windows 绝对路径写入当前对话输入框，且不会自动发送。
- 项目素材页新增“＋ 新建文件夹”：在哪一层创建就落在哪一层，项目根层新建会自动纳入扫描目录，创建后直接打开；空文件夹也可继续进入和创建下一级。
- 新建文件夹会拒绝 Windows 保留名、非法字符、相对越界与符号链接越界，已有同名目录会给出明确提示。
- 文件夹预览卡一级显示“改名 / 打开”；改名只调整目录名称，内部素材保持不变，并同步更新扫描目录及自动归档路径。
- 大文件夹改为只加载屏幕附近的图片、视频和音频，滚动到附近时再补载；资产卡先在内存中一次组装后挂载，并取消每张缩略图长期占用的独立渲染层。项目/文件夹切换的数据请求不再等待退场动画结束。
- 已浏览的项目和文件夹会保留最近 24 份内存快照；返回时先立即显示缓存，再在后台校对最新内容。手动刷新与移动、新建、改名、删除等结构变更会绕过或清理缓存，不会把旧目录重新写回。
- “每日练习”默认进入最新的日期文件夹，不再被“生成记录”等工具目录排到前面；非日期目录仍保留在“其他文件夹”中，可直接进入。
- “本周剩余”改为按所有近期任务日志中的真实额度事件时间取最新值，不再受旧任务索引时间或预览缓存影响；当前任务日志更新后会自动失效并在下一轮同步刷新。
- 配套 AssetBrowser 后端文件夹校验 25/25、改名 API 25/25 通过；16 路并发根目录创建全部写入扫描配置，无假成功或孤立目录；同名提交后文件监控仍保持有效。
- Windows 压缩包安装增强器前端；新建/改名要求目标电脑的配套 AssetBrowser 服务包含 POST/PATCH /api/folders，当前电脑已完成同步升级。
- 资产工作流目标测试 32/32 通过；额度同步目标测试 12/12 通过；Skill 管理现场分类、搜索、星标持久化、原生列表回退与详情打开均通过；全量跨平台测试 86/90 通过，4 项仅为 macOS 安装测试无法在 Windows 执行。
- 现场嵌入态验证：当前任务未关联项目时，“移动到项目…”可直接打开目标选择器；默认目标不会停留在素材原项目；工作区切换实际产生 90ms 退场和 190ms 入场动画。
- 现场嵌入态验收通过：新建入口可见、弹窗完整位于视口内、键盘焦点正确、相对路径会被拒绝、横向溢出为 0。
- 安装目录与本压缩包中的关键文件已进行 SHA-256 一致性核对。
