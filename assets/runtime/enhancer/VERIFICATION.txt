Codex Sidebar Enhancer - legacy Windows verification note

This directory is an optional, default-disabled compatibility adapter. It is not the preferred native Codex plugin.

The previous local snapshot contained machine-specific pass counts, timings, and an archive-consistency statement that could not be reproduced from the public repository. Those numbers have been removed and must not be used as current release evidence.

Current reproducible checks:

- `npm --prefix assets/runtime/enhancer test`
- `npm --prefix assets/runtime/asset-browser test`
- `python3 scripts/build-windows-bundle.py --check`
- `node scripts/verify-macos.mjs`

`build-windows-bundle.py` creates `codex-sidebar-enhancer-windows.zip` deterministically from the reviewed files under `assets/runtime/enhancer/`, updates `manifest.sha256.json`, and verifies that every archive entry matches the adjacent source bytes.

Installed-host behavior remains separate evidence. CDP attachment, task switching, live sidebar layout, and real AssetBrowser integration must be rechecked on the target Codex version before claiming host compatibility.
